# Data

Data files are not committed (they are gitignored). Put them here on each laptop:

```
data/
├── raw/
│   ├── train/00000001/00000001.{track,nodes,arcs,route}   80 trips
│   └── student_test/00000000/...                            10 trips
├── evaluator/        the 10 reserved trips, given on demo day (Laptop 1 only)
└── processed/        generated by scripts/build_dataset.py
```

Unzip `Student folder.zip` and move its `train/` and `student_test/` folders into `data/raw/`.

Rules:
- `evaluator/` is never used for training, feature selection, tuning or thresholds.
- Route files of evaluator trips are read only by the API's scoring step, never by the model or the UI.
